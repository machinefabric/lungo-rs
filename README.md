# lungo-rs

The Rust workspace of [lungo](https://github.com/machinefabric/lungo): the runtime, the code
generators, the `lungo` command, the tooling that builds lungo's distribution, and the tests.
lungo turns an ordinary Lake project into code for other languages — a Rust module generated
at Cargo build time, and C, Go, Python, Swift and TypeScript packages generated by the `lungo`
command. What lungo is and how to use it: <https://lungo.machinefabric.com/docs>.

This repository is a submodule of [lungo](https://github.com/machinefabric/lungo), beside the
support libraries (`lungo-go`, `lungo-py`, `lungo-ts`, `lungo-swift`), which the distribution
tooling and the end-to-end tests read from there. Clone lungo, not this repository alone:

```sh
git clone --recurse-submodules https://github.com/machinefabric/lungo.git
cd lungo/lungo-rs
```

## Layout

| Path | Contents |
| --- | --- |
| `crates/lungo-bir` | The Bridge IR data model and its verifier |
| `crates/lungo-protocol` | The versioned worker protocol |
| `crates/lungo-runtime` | The Rust port of Lean's runtime, its C ABI (`include/lungo.h`) and the wire format |
| `crates/lungo-capi` | The runtime as a C library (`liblungo`) |
| `crates/lungo` | Runtime support and facade types used by generated Rust |
| `crates/lungo-codegen` | The code generators: Rust, C, and the C, Go, Python, Swift and TypeScript bindings; the plugin protocol |
| `crates/lungo-driver` | The language-neutral pipeline, and in `worker/` the Lean worker, which reads Lean's compiler output and emits Bridge IR |
| `crates/lungo-build` | Build-script integration (Rust) |
| `crates/lungo-cli` | The `lungo` command |
| `runtimes/c` | The runtime's CMake and pkg-config files |
| `tools/lungo-dist` | Builds the distribution: a local one for development, and each artifact of a release (runtime archives, the XCFramework, the command, `lungo-py`'s wheels, the Go and Swift release trees) |
| `packaging/` | The templates of the `lungo` command's Homebrew formula, Debian and RPM packages |
| `examples/session` | A Lean state machine with proofs, used from Rust |
| `compiler-tests/` | Differential, property, integration, corpus, wire-format and polyglot (every language) tests |
| `runtime-tests/` | Inventories of the toolchain's native interface |

## Testing

```sh
elan toolchain install leanprover/lean4:v4.34.1
rustup target add wasm32-wasip1
cargo test --workspace --all-features
cargo check --manifest-path compiler-tests/stdlib-corpus/Cargo.toml
```

The end-to-end tests of the language bindings (`crates/lungo-cli/tests/polyglot.rs`) build a
local distribution from the support libraries beside this repository, and need CMake, Go,
Python, Node.js and, on macOS, Swift; on Windows also MinGW-w64 GCC and the
`x86_64-pc-windows-gnu` Rust target.
